# JARVIS Mobile

**JARVIS Mobile** is a production-grade, native Android voice AI assistant built in Kotlin with Jetpack Compose, Material 3, Coroutines/Flow, Room, and DataStore.

It is a standalone mobile port of the desktop assistant **"Mark LV" by FatihMakes** (credited under the Creative Commons Attribution-NonCommercial 4.0 International license, CC BY-NC 4.0).

---

## ⚡ Key Capabilities & Architecture

- **Real-Time Gemini Live Audio Loop**:
  - Direct WebSocket connection to Gemini Live (`gemini-3.1-flash-live-preview` primary, `gemini-2.5-flash-native-audio-preview-12-2025` as the single fallback rung, stepping only on quota or lost access; verify ids against Google's current list).
  - Streams 16 kHz mono 16-bit PCM from `AudioRecord` and outputs 24 kHz PCM via `AudioTrack` with low-latency streaming.
  - **Barge-In Detection**: Immediately interrupts speech output when user voice input is detected.
  - **Session Resumption**: Captures and replays server resumption tokens so network drops or restarts never wipe context.
  - **Self-Echo Suppression**: Acoustic feedback suppression prevents JARVIS from responding to its own voice.
  - Five selectable voices: Puck, Charon, Kore, Fenrir, Aoede.

- **Measured One-Shot Model Ladder**:
  - `GeminiClient` routes one-shot tasks (summaries, translation, code fixing, search analysis) through a measured priority ladder:
    1. `gemini-3.1-flash-lite-preview`
    2. `gemini-2.5-flash-lite`
    3. `gemini-2.5-flash`
    4. `gemini-3.5-flash` (verify ids against Google's current list)
  - Per-model cooldown timers: 5 minutes for HTTP 429, 30 minutes for 503/504, 6 hours for 404. All calls enforce timeouts $\ge$ 10 seconds.

- **Self-Describing Tool / Action Subsystem**:
  - Every action implements `Action` with typed parameters, Gemini-compliant schema generation, and exception-safe `execute()`.
  - Adding a new tool is a clean, single-file addition.
  - Bundled actions include:
    1. `open_app`: Fuzzy application matching via `PackageManager`.
    2. `set_volume`: Media, ring, alarm, notification volume with undo.
       `set_brightness`: Screen brightness with undo (asks for Modify system settings access).
    3. `toggle_flashlight`: Torch control via `CameraManager` with undo.
    4. `manage_connectivity`: Internet and Bluetooth panels (explaining Android 10+ WiFi rules).
    5. `control_media`: Play/pause/next/previous playback dispatch.
    6. `set_do_not_disturb`: Interruption filter control.
    7. `make_phone_call`: Contact/number call with safety approval.
    8. `send_sms`: Text composition with safety approval.
    9. `compose_message`: WhatsApp, Telegram, and Email deep links.
    10. `lookup_contact`: Address book search via `ContactsContract`.
    11. `set_alarm` & `set_timer`: Native clock alarms and timers.
    12. `create_reminder`: Persistent reminders surviving reboot via `WorkManager`.
    13. `calendar_event`: Read upcoming agenda and insert events.
    14. `navigate_to`: Turn-by-turn directions via Google Maps.
    15. `get_weather`: Live atmospheric forecast via Open-Meteo.
    16. `web_search`: Multi-mode search (news, research, price, compare).
    17. `open_browser`: URL navigation in default browser.
    18. `clipboard_assistant`: Summarise, translate, explain, or fix copied text.
    19. `file_operations`: Read, create, rename, delete files with undo & safety guard.
    20. `check_device_health`: Real-time battery, temp, RAM, storage, and network speed.
    21. `inspect_visual_input`: reports camera/screen availability only. Camera (CameraX) and screen (MediaProjection) streaming into the live session are NOT implemented yet.
    22. `accessibility_control`: Tap, scroll, back, home, recents, and screen reading via `AccessibilityService`.
    23. `play_video`: Media3/ExoPlayer video feed with audio ducking.
    24. `remember_fact`: Commit persistent preferences to Room.
    25. `recall_memory`: Search offline memory.
    26. `plan_and_execute`: Autonomous multi-step goal chaining.

- **Local-Only Persistent Memory (Room Database)**:
  - Facts, identity tokens, preferences, and session recaps stored securely in an offline Room database.
  - Compact index injected dynamically into system prompt; remaining facts searchable via `recall_memory`.
  - Dedicated Memory Vault screen with full-text search and individual fact deletion.

- **Cryptographic Safety Guard & Undo Stack**:
  - Reversible actions push to a shared undo stack (`UndoStack`), reversed at any time by saying "undo".
  - Sensitive or irreversible operations (phone calls, SMS, WhatsApp sends, deleting files) require explicit user tap confirmation with a one-time cryptographic token generated by `SafetyGuard`.

- **Futuristic Holographic HUD UI**:
  - Center holographic animated avatar lip-syncing to voice audio amplitude and formant frequencies, showing state via gaze and rotation (listening, thinking, speaking, idle).
  - Real-time reactive waveform reflecting microphone input and assistant speech.
  - Scrolling transcript with dynamic telemetry cards (Weather, Hardware Diagnostics, Web Results, Video Player).
  - Quick command chips for instant voice-assisted queries.
  - Dynamic HUD theme recolorable via interactive Hue slider (0–360°).

- **Always-On Voice & Accessibility**:
  - `JarvisVoiceService`: Background microphone foreground service that sleeps after 2 minutes of silence to conserve battery.
  - `JarvisAccessibilityService`: Enables automated UI gestures and on-screen reading.
  - `JarvisOverlayService`: Floating HUD bubble (`SYSTEM_ALERT_WINDOW`).
  - `JarvisTileService`: Quick Settings tile for immediate voice listening.

## 🛠️ Build & Setup Instructions

### Prerequisites
- Android Studio Ladybug or newer.
- Android SDK 35, JDK 17 or JDK 21.
- Minimum supported device: Android 8.0 (API 26), target: Android 15 (API 35).

### API Key Configuration
1. Open the **Secrets panel in AI Studio** or create a `.env` file in the project root:
   ```properties
   GEMINI_API_KEY=your_actual_gemini_api_key_here
   ```
2. Alternatively, enter your Gemini API key directly into the **Settings Drawer** upon first launch. Keys are stored with AES-256-GCM encryption in `EncryptedSharedPreferences`.

### Building
In terminal or Android Studio:
```bash
gradle assembleDebug
```
To run local JVM & Robolectric tests:
```bash
gradle :app:testDebugUnitTest
```

## Build the APK with GitHub Actions

1. Create a GitHub repo and push this folder to it (the workflow is already at `.github/workflows/build-apk.yml`, and the Gradle wrapper is included).
2. Open the repo's **Actions** tab. Every push runs unit tests, then builds a **debug APK**.
3. Open the finished run, scroll to **Artifacts**, and download `jarvis-mobile-debug-apk`. Unzip it and install the `.apk` on your phone (allow "install unknown apps").
4. **Optional signed release APK:** add these repository secrets (Settings -> Secrets and variables -> Actions), then run the workflow manually (**Run workflow**) or push a tag like `v1.0.0`:
   - `KEYSTORE_BASE64`: your keystore, encoded with `base64 -w0 my-upload-key.jks`
   - `STORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`

The debug APK needs no secrets: the Gemini API key is typed into the app on first launch.

## Vision (camera and screen)

`inspect_visual_input` streams about one JPEG frame per second into the live session, one source at a time.
- **Camera** (CameraX): needs the Camera permission and the app on screen. Frames show the user and their room.
- **Screen** (MediaProjection): Android shows its own "start recording or casting" prompt and nothing is captured until you tap Start. A persistent notification with a Stop button is shown, and sharing stops by itself after 10 minutes or when the session ends. Frames show the phone screen.

## Known gaps

- The wake word is an energy gate, not a real "Hey Jarvis" detector (no openWakeWord/Porcupine model). It also needs the overlay permission to open the HUD from the background on Android 10+.
- Memory search uses SQL `LIKE`, not Room FTS, and the prompt carries up to 30 full facts instead of a core plus a key index.
- The system prompt is a Kotlin string in `SystemPromptManager.kt`, not an editable asset file.
